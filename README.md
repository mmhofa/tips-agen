# tips-agent

یک عامل پایتونی برای جست‌وجوی نکته‌های تازه دربارهٔ هوش مصنوعی عامل‌محور، ساختن چند پیشنهاد دوزبانه و انتشار یک نکته در کانال تلگرام.

## کارهایی که برنامه انجام می‌دهد

در هر اجرا، برنامه:

1. با ابزار DuckDuckGo وب را برای منابع جدید و تاریخ‌دار دربارهٔ AI agentها جست‌وجو می‌کند.
2. با مدل DeepSeek در سرویس AvalAI، ۳ تا ۵ نکته با عنوان و متن انگلیسی و فارسی تولید می‌کند. متن فارسی روان است و ترجمهٔ کلمه‌به‌کلمه نیست.
3. نشانی منبع هر پیشنهاد را با نتیجه‌های جست‌وجو تطبیق می‌دهد و پیشنهادهای شبیه نکته‌های قبلی را حذف می‌کند.
4. یک پیشنهاد را انتخاب می‌کند و همراه با سطح دشواری و پیوند منبع به کانال تلگرام می‌فرستد.
5. نکتهٔ ارسال‌شده را در `data/posted_tips.json` ذخیره می‌کند. پایگاه برداری Chroma در `data/chroma_db` از این سابقه برای تشخیص نکته‌های تکراری استفاده می‌کند و در صورت نیاز از فایل JSON دوباره ساخته می‌شود.

## نیازمندی‌ها

- Python 3.12
- [uv](https://docs.astral.sh/uv/)
- کلید API سرویس AvalAI
- ربات تلگرام که مدیر کانال باشد
- اتصال به اینترنت برای AvalAI، جست‌وجوی DuckDuckGo و Telegram Bot API

## راه‌اندازی محلی در ویندوز

در PowerShell، از پوشهٔ پروژه اجرا کن:

```powershell
Copy-Item .env.example .env
```

فایل `.env` را باز کن و مقادیر واقعی را فقط روی رایانهٔ خودت وارد کن:

```dotenv
TELEGRAM_BOT_TOKEN=توکن_ربات
TELEGRAM_CHANNEL=@نام_عمومی_کانال
AVALAI_API_KEY=کلید_AvalAI
```

نام کانال باید به شکل `@channel_username` باشد. فایل `.env` در Git نادیده گرفته می‌شود؛ آن را commit یا در پیام‌ها و گزارش‌ها منتشر نکن.

سپس وابستگی‌ها را نصب و برنامه را اجرا کن:

```powershell
uv sync --locked
uv run python generate_tip.py
```

هر اجرای موفق، یک پیام در کانال منتشر می‌کند. فایل `send_hello.py` نمونهٔ سادهٔ ارسال پیام ثابت است و برای انتشار نکته‌های تولیدشده لازم نیست.

## اجرای خودکار با GitHub Actions

Workflow در `.github/workflows/publish-tip.yml` قرار دارد. برای فعال‌کردن آن:

1. در صفحهٔ مخزن GitHub به **Settings → Secrets and variables → Actions** برو.
2. سه Repository secret با نام‌های زیر بساز و مقدار واقعی را در فیلد Secret هرکدام قرار بده:
   - `AVALAI_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL`
3. مطمئن شو ربات در کانال مدیر است و دسترسی ارسال پیام دارد.
4. از تب **Actions**، workflow با نام **Publish agentic AI tips** را انتخاب کن و **Run workflow** را بزن تا یک بار دستی اجرا شود.

زمان‌بندی فعلی روزانه سه اجرا در ساعت‌های 09:15، 15:15 و 21:15 منطقهٔ زمانی `America/Los_Angeles` است. زمان‌بندی را می‌توان در بخش `schedule` همان فایل workflow تغییر داد. GitHub ممکن است اجرای زمان‌بندی‌شده را با کمی تأخیر شروع کند.

پس از اجرا، workflow تغییرات `data/posted_tips.json` را با حساب Actions به مخزن push می‌کند تا سابقه بین اجراها حفظ شود. پوشهٔ `data/chroma_db` در مخزن ذخیره نمی‌شود؛ برنامه آن را از JSON بازسازی می‌کند. برای این کار، دسترسی نوشتن محتوا (contents: write) در workflow لازم است.

## ساختار داده

- `data/posted_tips.json`: تاریخچهٔ نکته‌های منتشرشده، شامل هر دو زبان، تاریخ، شناسهٔ پیام تلگرام و منبع.
- `data/chroma_db/`: پایگاه برداری محلی برای یافتن موارد مشابه؛ با Git دنبال نمی‌شود.
- `.env.example`: فقط الگوی خالی متغیرهای محیطی.

## امنیت

- کلیدهای واقعی را در `.env` محلی یا GitHub Actions Secrets نگه دار؛ آن‌ها را در کد یا `README.md` قرار نده.
- اگر کلیدی قبلاً commit یا منتشر شده، آن را از سرویس مربوطه باطل و کلید تازه بساز. حذف فایل از commitهای جدید، نسخه‌های قبلی تاریخچهٔ Git را پاک نمی‌کند.
- در مخزن عمومی، کد، تاریخچهٔ نکته‌ها و گزارش‌های Actions قابل‌مشاهده‌اند. Secrets در صفحهٔ مخزن نمایش داده نمی‌شوند؛ بااین‌حال خروجی workflow نباید حاوی مقدار محرمانه باشد.

## وابستگی‌ها

وابستگی‌ها در `pyproject.toml` تعریف و نسخه‌های دقیق در `uv.lock` ثبت شده‌اند. نصب قفل‌شده با `uv sync --locked` انجام می‌شود.
